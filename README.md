# إليكَ — رسائل صغيرة

نسخة ثابتة من الموقع مناسبة للنشر مجانًا باستخدام GitHub Pages.

## إضافة رسالة جديدة
افتحي `js/letters.js` وأضيفي عنصرًا داخل `window.LETTERS` بهذا الشكل:

```js
{
  id: 1,
  title: "عنوان الرسالة",
  content: `اكتبي نص الرسالة هنا...`,
  opensAt: "2026-11-08T09:00:00+03:00"
}
```

- `id`: رقم مختلف لكل رسالة.
- `title`: عنوان الرسالة.
- `content`: محتوى الرسالة. استخدمي backticks كما في المثال إذا كان النص على عدة أسطر.
- `opensAt`: موعد فتح الرسالة بالتوقيت المحلي. الأردن حاليًا +03:00.

لإضافة رسالة أسبوعية، أضيفي رسالة وحددي موعد فتحها بعد أسبوع من سابقتها. الموقع لا ينشئ الرسائل تلقائيًا؛ الرسائل تُجهّز مسبقًا.

## النشر على GitHub Pages
1. أنشئي مستودعًا عامًا جديدًا باسم `little-letters`.
2. ارفعي محتويات هذا المجلد إلى جذر المستودع، بحيث يكون `index.html` في المستوى الأول.
3. افتحي Settings ثم Pages.
4. تحت Build and deployment اختاري Deploy from a branch.
5. اختاري `main` و`/(root)` ثم Save.
6. انتظري اكتمال النشر، وسيظهر رابط الموقع في صفحة Pages.

## تنبيه خصوصية مهم
GitHub Pages يستضيف موقعًا ثابتًا. محتوى الرسائل موجود داخل ملفات JavaScript ويمكن لأي شخص لديه الرابط أو يعرف كيف يفحص ملفات الموقع الوصول إليه، حتى لو كانت الرسائل مغلقة في الواجهة. لا تضعي رسائل أو معلومات شديدة الخصوصية في هذه النسخة. كما أن مواعيد الفتح هنا تتحكم بما يظهر في الواجهة فقط وليست حماية أمنية.
